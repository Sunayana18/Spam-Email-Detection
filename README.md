Spam Email Detection:

A machine learning project that detects whether a message is Spam or Not Spam.

Technologies Used:

Python
Pandas
Scikit-learn
Streamlit
Multinomial Naive Bayes
CountVectorizer

How It Works:

The project uses CountVectorizer to convert text into numerical features and a Multinomial Naive Bayes model to classify messages as Spam or Not Spam.
